05
User Journey Flows

Step-by-step paths for both roles — from sign-up to a signed lease.

🔍
Renter Journey
Register → Onboard → Swipe → Match → Chat → Lease
1
Register & Sign In
Email + password · role auto-set to renter
POST /api/auth/register
2
AI Onboarding Chat
Multi-turn conversation extracts city, budget & preferences automatically
POST /api/chat
3
Discover Properties
Filtered by city + budget. Each card shows AI-computed match score 75–99%
GET /api/properties
4
Swipe Right / Up
Creates a PropertyInterest (pending). Free users: 2 swipes/day
POST /api/swipe
Free → 2/day Pro → unlimited
5
Landlord Approves
A Match record is created and appears in the Matches tab
GET /api/matches
6
Real-time Chat
WebSocket room opened. Messages persisted, read receipts tracked
WS join_chat / send_message
7
Generate Lease ✓
AI produces legally-structured HTML lease agreement
POST /api/lease/generate
🏠
Landlord Journey
Register → List → Review → Approve → Chat → Close
1
Register as Landlord
Email + password · role set to landlord · redirected to dashboard
POST /api/auth/register
2
AI-Assisted Property Form
Chat with AI assistant that extracts title, price, rooms & amenities via function calling
POST /api/landlord/extract-property
3
Upload & Analyse Photos
GPT-4V auto-generates Hebrew description and relevant tags from photos
POST /api/upload · /api/analyze-property-image
4
Publish Listing
Status → available. Property appears in renters' swipe deck immediately
POST /api/properties
5
Review Interested Renters
Centralised inbox shows all pending interests across all properties
GET /api/landlord/properties/:id/interests
6
Approve / Reject
Approve creates a Match. Reject notifies renter. Can reopen at any time.
POST /api/landlord/approve · /reject · /reopen
Approve → Match Reject → notify
7
Chat & Close Deal ✓
Real-time chat → generate lease → set property to rented
POST /api/lease/generate · /status

Layered defences covering authentication, request throttling, and subscription enforcement.

🔐 Authentication
🎫
Bearer token via itsdangerous URLSafeTimedSerializer
7-day TTL
🔒
bcrypt password hashing on every stored credential
🛡️
@require_auth decorator enforced on all private routes
🌐
CORS origin whitelist enforced in production (no wildcard)
🚦 Rate Limits
🔑
Login / register — IP-level throttle
10 / 15 min
💬
Chat messages — per-user hourly cap
60 / hour
⏱️
Chat interval — min time between messages
2 s min
📏
Message length — hard cap per request
2 000 chars

🆓
Free tier — limited daily swipes, server-enforced
2 / day
⭐

Unlimited
