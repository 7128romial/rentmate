🔐 7 · Security & Rate Limiting
Authentication
  • itsdangerous URLSafeTimedSerializer tokens
  • bcrypt password hashing
  • 7-day token TTL (configurable)
  • @require_auth decorator on all private routes
  • CORS origin whitelist enforced in production
Rate Limiting
  • Login / register: 10 per IP / 15 min
  • Chat: 60 messages / user / hour
  • Chat interval: 2 seconds minimum
  • Message length: 2 000 chars max
  • Swipes: 2 / day (Free), unlimited (Pro)
Subscription Tiers
  • Free 2 swipes / day
  • Pro Unlimited swipes
  • Stripe payment integration (ready)
  • subscription_until enforced server-side
  • 7-day trial period supported
